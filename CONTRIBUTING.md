# Contributing to Ambience Garden

Thank you for your interest in contributing to Ambience Garden!

## How to Contribute

### Bug Reports

If you've found a bug, please [open an issue](https://github.com/MikeOnDeck/ambience-garden/issues/new/choose) using the bug report template. Include:

- Minecraft version and Fabric Loader version
- Steps to reproduce the issue
- Expected vs. actual behavior
- Relevant logs or screenshots

### Sound and Biome Suggestions

Have an idea for a new ambient sound or biome coverage? Please [open an issue](https://github.com/MikeOnDeck/ambience-garden/issues/new/choose) using the sound/biome suggestion template. Include:

- Which biome(s) or environment(s) should have the sound
- Description of the sound (e.g., "wind howling", "leaves rustling")
- When it should play (time of day, weather, player location)
- Any reference examples or inspiration

### Pull Requests

Pull requests are welcome! Before submitting a large PR, consider opening an issue first to discuss your proposed changes.

#### Guidelines

1. **Code style**: Follow the existing code style in the project
2. **Testing**: Test your changes in-game before submitting
3. **Commit messages**: Write clear, descriptive commit messages
4. **Documentation**: Update the README or other docs if your changes affect usage

#### Development Setup

See the [Building from Source](README.md#building-from-source) section in the README.

## Review Process

All contributions are reviewed by MikeOnDeck. Please be patient - I review PRs as time permits.

## Code of Conduct

Be respectful and constructive. This is a welcoming project for all skill levels.

## Questions?

Feel free to open a [GitHub Discussion](https://github.com/MikeOnDeck/ambience-garden/discussions) or comment on an existing issue.
